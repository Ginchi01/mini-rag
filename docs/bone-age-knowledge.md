# 骨龄与儿童生长发育（示例知识库）

> 这是给 `mini_rag.py` 用的示例文档。你可以换成任何内容（公司制度、产品手册、论文笔记）。
> RAG 的任务是：只根据这里的文字回答，不准自己编。

## RUS-CHN 标准是什么

RUS-CHN 是中国儿童骨成熟度评价标准，由张绍岩等人制定，全称是「中国人手腕骨发育标准」。
它把左手腕部 20 个关节的骨骺发育程度分成若干等级，每个等级对应一个分值，
累加后查表得到骨龄。RUS 指的是桡骨（Radius）、尺骨（Ulna）和掌指骨（Short bones），
CHN 指中国。

与 Greulich-Pyle 图谱法相比，RUS-CHN 是按关节逐级计分的，属于计分法；
GP 法是把待评估的 X 光片与标准图谱整体比对，属于图谱法。计分法的一致性更好，
但耗时更长。

## 骨龄评估的临床意义

骨龄反映骨骼的成熟程度，比实际年龄更能代表个体的生长发育水平。
临床上常用于：性早熟的诊断、矮小症的病因分析、生长激素治疗的疗效监测、
以及法医学中的年龄推断。

骨龄与实际年龄的差值（BA-CA）是常用指标。差值超过 ±2 岁通常提示需要进一步检查。

## 影响骨龄评估准确性的因素

1. **拍摄体位**：左手掌必须平贴暗盒，手指自然分开。体位不正会导致关节投影变形。
2. **曝光条件**：曝光不足时骨骺线看不清，曝光过度时软组织细节丢失。
3. **图像分辨率**：指骨末节和腕骨的细节需要足够分辨率，常规建议不低于 300 dpi。
4. **性别差异**：男女的骨龄换算表和多项式系数不同，必须分别建模。
5. **左右手差异**：临床标准以左手为准，右手X光片需要换算或重新拍摄。

## 深度学习在骨龄评估中的应用

传统方法依赖医生逐关节判读，耗时且一致性差。深度学习方案大致分两类：

**端到端回归**：用 ResNet 之类的网络直接输出骨龄数值。优点是实现简单、
只需要一个模型；缺点是不可解释，一旦结果偏差，无法判断是哪里出错。

**两级级联**：先检测关节位置，再对每个关节做发育等级分类，
最后按评分表计分。优点是每一步可解释、可单独评估、可局部替换；
缺点是工程量大，误差会逐级累积（漏检 → 分类错 → 计分错）。

在医学影像场景，可解释性通常是硬要求，因此级联方案更常见。

## 常用评估指标

- **MAE（平均绝对误差）**：预测骨龄与真实骨龄的绝对差值的平均。单位是岁。
  对离群样本不敏感，适合描述平均偏差。
- **RMSE（均方根误差）**：对大误差惩罚更重。如果 RMSE 明显大于 MAE，
  说明存在少量严重偏离的样本。
- **±1 年准确率**：预测值落在真实值 ±1 岁范围内的比例。
  临床上常把这个作为「可接受」的标准。
- **Within-1-grade 准确率**：序数分类专用指标。关节等级判错一级但方向相邻时，
  在临床上通常可以接受，因此单独统计这个比例。
- **Spearman 相关系数**：衡量预测值与真实值的秩相关性，不关心绝对误差大小。

## 骨龄评估的常见失败模式

1. **快速生长期样本**：青春期前后骨龄变化快，同样的等级差异对应更大的年龄差。
2. **拍摄角度偏移**：手指展开角度不同，关节投影形态改变，分类模型容易误判。
3. **金属伪影**：戒指、夹板等会在 X 光上形成高亮伪影，干扰关节检测。
4. **低龄样本**：幼儿腕骨尚未完全骨化，等级分布集中，区分度低。
5. **超龄样本**：骨骺完全闭合后，等级不再变化，模型无法区分 16 岁和 18 岁。

## 检索与生成（RAG）在医疗场景的注意点

RAG 的价值在于把回答约束在给定资料内，降低幻觉。医疗场景下这一点尤其重要：
模型不能凭记忆编造诊断标准。

工程上要做的三件事：一是知识库必须有版本和来源标注；二是回答必须带引用，
让人能追溯到原文；三是资料里没有的内容要明确拒答，而不是给一个"看起来合理"的答案。

切分策略会直接影响召回效果。固定长度切分简单稳定，但容易把一条完整的判定规则
拦腰截断；按段落或标题切分更贴合语义，但长度不均。实践中常见做法是优先按标题和
段落切，超长段再按固定长度二次切分，并保留一定重叠。
